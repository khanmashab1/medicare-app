🛠️ TECHNICAL REQUIREMENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- Single HTML file (no build tools, no TypeScript)
- React 18 via CDN (unpkg), Babel standalone via CDN
- Supabase JS v2 via CDN (jsdelivr)
- All styles in one <style> tag using CSS variables above
- No Tailwind — use pure CSS with the variable system
- React hooks: useState, useEffect, useCallback, useMemo
- Skeleton loaders (animated shimmer) while fetching
- Toast notifications: fixed bottom-right, auto-dismiss 3s
- Loading spinner on all async actions
- Error states: show error message if fetch fails with retry button
- Responsive: sidebar on desktop (≥768px), bottom nav on mobile
- Smooth view transitions (CSS opacity + translateY)
- All cards: border-radius var(--radius), box-shadow var(--shadow-card)
- Primary buttons: background var(--gradient-brand), color white, box-shadow var(--shadow-btn)
- Status badge colors strictly: Upcoming=teal, Completed=green, Cancelled=coral, Pending=yellow
- Initials avatars: extract first letter of each word in name, teal gradient background
- Star rating: filled ★ = gold, empty ★ = var(--border) color
- Re-fetch data after every mutation (insert/update) to keep UI in sync
- Handle empty states gracefully with helpful messages and icons
